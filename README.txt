うごく恐竜ゲーム（アセット完全版）
====================================

■ このZIPに入っているもの
- index.html ・・・ ゲーム本体
- assets/dino.png ・・・ 主人公の恐竜
- assets/rock_small.png ・・・ 小さい岩
- assets/rock_big.png ・・・ 大きい岩
- assets/thorn.png ・・・ トゲ草
- assets/ptero.png ・・・ 翼竜
- assets/meteor.png ・・・ 隕石
- assets/meat.png ・・・ にくアイテム

■ 遊び方
1. ZIPを解凍します
2. index.html をダブルクリックします
3. ブラウザでゲームが開きます

■ 操作
- クリック / タップ / Space：ジャンプ
- 空中で連続タップ：ふわっと長く浮く
- Mキー：BGM ON / OFF

■ BGMを追加したいとき
index.html と同じ階層に bgm.mp3 を置いてください

例：
index.html
bgm.mp3
assets/

■ メモ
- スコアが上がると新しい障害物が増えます
- GitHub Pagesにアップしても動かせます
